A soft, ribbon-inspired Chrome theme built from four flat colors: a coral pink window frame and tab strip, a blush-white toolbar and bookmark bar, a gentle lavender accent, and a porcelain new-tab page. The text colors are tuned so tabs, the toolbar, bookmarks and the address bar stay comfortable to read on every surface, and a deeper coral frame keeps private windows distinct. Each layer is painted as one solid color, so the window stays light and uncluttered while you work.
